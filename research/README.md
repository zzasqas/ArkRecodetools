## 為什麼不進版控

這裡是研究過程與筆記，不是程式碼也不是線上服務會讀的資料。
Railway 不讀、網頁工具不讀，push 上去沒有實質效益，反而讓 commit 紀錄被文件改動洗掉。

要把某一份分享出去時再單獨加：

```bash
git add -f research/RTA_選角速查.md
```
