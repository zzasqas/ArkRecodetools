怎麼分享我的角色庫？

抓一次自己的角色，就能丟連結或圖片給別人——求配對建議或賣帳號時很方便。 收到的人什麼都不用裝。

  1. 裝一次擷取工具（只需一次，二選一）：
    • Chrome / Edge 外掛（推薦，最簡單）： 從 Chrome 線上應用程式商店安裝 → 點「加到 Chrome」即可（Edge 等 Chromium 瀏覽器也適用）。
    • Tampermonkey 腳本（進不了 Chrome 商店時用——例如 360／QQ／搜狗等瀏覽器）：先裝 Tampermonkey（免費擴充）， 再點 → 安裝「角色列表擷取」腳本（按「安裝」即可）。
  2. 用瀏覽器開網頁版遊戲登入（網址 game-arkre-labs.ecchi.xxx； PC 客戶端不行，因為要攔瀏覽器封包）。登入成功後右上角自動跳出小面板 → 點 「🔗 直接在檢視器開啟」，就會開這一頁並帶入你的角色。
  3. 篩掉不要的、再分享：用上方篩選（元素／職業／星）把三星、四星等不重要的先濾掉， 然後：
    • 🔗 複製分享連結 → 貼給對方，他點開就看到你篩選後的角色（可自己再篩，適合問配對）。
    • 🖼️ 匯出成圖片 → 一張 PNG 存到「下載」資料夾，貼 Discord／賣帳號貼文最直接。

分享出去的只有「當下篩選後顯示」的角色，所以先濾再分享就不會露出一堆下水道三星。
