📖 如何取得 RTA JSON（使用教學）

🔒 安全說明

此工具不會讀取、儲存或上傳你的帳號密碼。它只讀取遊戲伺服器在你登入成功後、已經回傳到你瀏覽器的資料——跟你在遊戲裡看 RTA 戰績是完全一樣的內容。腳本原始碼公開可查，任何人都能逐行審閱。

安裝步驟（一次性）

1. 安裝「篡改猴 Tampermonkey」瀏覽器外掛
  • Edge：Edge 擴充商店 · 篡改猴 →
  • Chrome：於 Chrome 線上應用程式商店搜尋「Tampermonkey」安裝。
2. 安裝 RTA 匯出腳本：點此下載 RTA 匯出腳本（.user.js）→，下載後直接拖入瀏覽器視窗，篡改猴會跳出安裝確認頁，點「安裝」即可。安裝前可看到完整原始碼、可自行檢查；腳本只比對遊戲網域，不在其他網站執行。

每次使用方法

  1. 用瀏覽器開遊戲網頁版：前往 www.ero-labs.com 登入，跟平常一樣操作。
  2. 等面板自動彈出：登入成功後，頁面右上角會出現深色面板，顯示「✅ RTA 擷取成功：N 場」，無需手動觸發。
  3. 點「下載 JSON」：檔案會存到瀏覽器預設下載位置。
  4. 匯入本頁：把下載的 rta_你的名字_日期.json 拖進上方的匯入區，即可看到你自己的 RTA 分析。

檔案裡有什麼

account你的遊戲暱稱
cuid你的遊戲 ID（公開數字，非密碼）
logs[].Role1List對戰雙方的出場角色
logs[].BanList雙方 ban 掉的角色
logs[].WinCUID獲勝方 ID

ℹ️ 檔案裡沒有帳號密碼、Token、裝備詳情或帳戶操作權限，只有對戰紀錄。全程於你的瀏覽器本地處理，資料不會上傳。

如何自行確認腳本安全

  • 👁️ 直接看原始碼：篡改猴 →「已安裝腳本」→ 點腳本名稱看完整程式碼（不到 200 行）。
  • 🌐 看權限宣告：安裝頁頂部的 @match 只有遊戲網域、@connect 只有 game-arkre-labs.ecchi.xxx（連不到其他地址）。
  • 🔍 用 DevTools 看實際請求（進階）：登入時按 F12 →「Network」→ 篩 RouterHandler，會看到腳本只發一條、目標與遊戲本身相同。
  • 📦 打開 JSON 看內容：用記事本開 .json，裡面只有對戰紀錄。

腳本大致在做什麼（簡要）

以下為簡要說明。若你仍不放心，請自行逐行審閱原始碼判斷，使用與否風險自負。

腳本只做一件事：在你登入遊戲、伺服器把資料回傳到瀏覽器後，「旁聽」到登入回應（含一次性查詢票券 AID／SessionID），用它向遊戲伺服器查一次 RTA 戰績——這一步跟你在遊戲裡點開「戰績」完全一樣——再把結果整理成 JSON、在右上角顯示下載鈕。它不修改任何請求、不攔截內容、不自動外傳；票券一次性，查完即失效。
